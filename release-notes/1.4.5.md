# 1.4.5

把「知识库自己的历史」和「段级就地改写」补上，并清掉一个从来没有注册过的工具。

## 内嵌快照

- `kb_init` 建库时顺便 `git init` 并提交初始快照（库目录不是 git 仓库、或系统没有 git 时静默跳过）。
- `kb_write` / `kb_rename` 成功后自动提交一次，commit message 形如 `autosnap: 3 处变更`，回执里多一行 `快照: …`。
- 新增 `kb_vcs_status`：最近几条快照 + 未提交改动。
- 配置 `git: false` 可整体关掉（建库、写入、改名都不再提交）。
- 快照只在**写入/改名成功后**发生，不在每次解析后发生——读库不会往历史里塞噪声。

## 段节点可写

- `kb_write mode=node` 的 `target` 现在也接受 `## 段` 的 TID（如 `doc:03-build:3.1`）：只替换该段正文，标题行原样保留。
- 段内已经含有 `<node>` / `<tscl>` 标签时拒绝改写（避免把结构改坏），提示改用「路径 + `mode=replace`」。

## 清理

- 删掉 `cmdDump`：它从 0.4 起就没有对应工具，属于死代码。
