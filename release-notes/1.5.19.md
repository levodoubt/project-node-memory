# 1.5.19

面板中栏的默认视图从**整齐树**换成**电路板**。树没有坏，只是它只能往一个方向长：一个四十几个文件的目录会排成一块几百像素宽、上万像素高的竖带，「适应视图」把缩放压到 0.05，字全糊成点。电路板换成二维面积细分——面积本身带信息，层级和布局是同一件事。

## 改了什么

1. **板 = 库，模块 = 目录，焊盘 = 叶子节点**：模块面积 = 它内含的节点数占全库的比例（squarified treemap），模块里递归铺下一层；**没有子节点的节点不再画成框**，画成一个小焊盘。默认铺 5 层，可在图设置或「设置」里改 2–8。
2. **下钻保持外形**：点模块（或双击芯片）钻进下一层时，新板按这块模块的原始宽高比缩放——布局和上一层里那块一模一样，只是放大。面包屑 / `↑` / Esc 回上一级。
3. **排线是真的引用**：正文里的 `[[node=]]` / `[[tscl=]]` 现在画成板上的走线（宿主 `/tree` 一次带回全部边，`?graph=0` 可关）。只走横、竖与拐角处 6px 的 45° 切角；同一条车道不重叠；打分时优先避开模块与焊盘。悬停或选中一个节点，它和它的对端焊盘一起变蓝，其余排线压到 22%。
4. **双向同步**：画布上点模块，左栏那棵树会展开并滚到对应行；左栏点条目，画布跟着下钻或聚焦到那一层。
5. **顶栏「设置」**：板底 / 模块填充 / 排线 / 焊盘四个不透明度、焊盘大小、排线线宽、丝印字号、最大层数，外加一键恢复默认。只影响显示，存在 localStorage。
6. **左右栏可拖拽调宽**（6px 抓手），宽度也记在 localStorage。

## 顺手修掉的

板上的颜色全部改成写在内联 `style` 上，样式表只留结构与指针样式。起因是一个很能骗人的现象：热更新只换模块不换 DOM，旧的 `<style>` 还挂在页面上，于是 `.nkb-bpad circle{fill:rgba(128,128,128,.5)}` 把每个焊盘的 `fill="none"` 盖成灰底——看起来「所有焊盘都是实心的」，而变的只是灰底，描边一直没生效。SVG 的表现属性（`fill=` / `stroke=`）优先级低于任何同名 CSS 规则，这类覆盖不会报错，只会让颜色「莫名不对」。
